# Dynamic Menu — المنيو + لوحة التحكم + السلة

## التشغيل (على Antigravity أو أي جهاز)
```bash
npm install
ADMIN_PASSWORD=كلمة_مرورك npm start      # Windows PowerShell:  $env:ADMIN_PASSWORD="xxxx"; npm start
```
- المنيو للعملاء:      http://localhost:3000
- لوحة التحكم:         http://localhost:3000/admin
- بدون `ADMIN_PASSWORD` كلمة المرور الافتراضية `admin123` — **غيّرها قبل النشر**.
- يحتاج Node.js 18 أو أحدث.

## لوحة التحكم
- إضافة / تعديل / حذف / ترتيب: البيتزا، الباستا، الجانبيات، الإضافات، المشروبات.
- **رفع صورة المنتج بجودة عالية**: اضغط على الصورة أو اسحب الملف عليها. يقبل JPG / PNG / WebP لحد 25MB.
  النظام يحفظها بجودة عالية (حتى 2000px) ويجهّز نسخ أصغر للموبايل تلقائيًا، ويعرض تقييم الجودة.
  - الأفضل: **PNG شفاف (بدون خلفية) بعرض 1500px أو أكثر** ← يظهر على الشريط البرتقالي زي تصميم المنيو.
  - الصورة اللي ليها خلفية تظهر كصورة مستطيلة بحواف مدورة.
- أسعار كل مقاس، أسعار حشو الجبنة، إخفاء صنف، "نفذت الكمية".
- الباستا: صورة منفصلة لكل نوع (بنه / فوتوتشيني).
- التغييرات لا تظهر للعملاء إلا بعد **حفظ التغييرات** (أو Ctrl+S).

## لوجو المطعم والثيم
- من الداشبورد ← **إعدادات**: ارفع اللوجو (يفضّل PNG شفاف بعرض 600px أو أكثر) واكتب اسم المطعم.
  اللوجو يظهر أعلى المنيو في المنتصف وكأيقونة للموقع في المتصفح. لو مفيش لوجو يظهر اسم المطعم.
- "شكل المنيو للعملاء": تلقائي (حسب جهاز العميل) / فاتح دائمًا (زي المنيو المطبوع) / داكن دائمًا.
  لو اللوجو غامق اختار "فاتح دائمًا" عشان يظهر بوضوح.

## السلة والإضافات (للعميل)
- البيتزا والباستا: زر "أضف للطلب" ← نافذة فيها الصورة + الإضافات (Toppings / Cheese / Sauces) + ملاحظات + الكمية.
- الجانبيات والإضافات المنفصلة والمشروبات: زر + / − مباشر.
- شريط "عرض الطلب" أسفل الشاشة يعرض السلة والإجمالي (محفوظة في متصفح العميل).
- زر **Checkout** في السلة يفتح صفحة إتمام الطلب (تفاصيلها تحت).

## إتمام الطلب وإرساله على واتساب
العميل بيدخل: الاسم، الموبايل، المنطقة (للدليفري)، العنوان بالتفصيل، الفرع، ملاحظات على الطلب، ويختار:
- **الاستلام:** دليفري (بيضيف رسوم التوصيل الخاصة بالمنطقة المحددة) أو تيك أواي.
- **الدفع:** كاش عند الاستلام (للمندوب أو من المطعم) / انستا باي / محفظة إلكترونية.
  لو اختار انستا باي أو المحفظة بيظهرله المبلغ + زر نسخ للعنوان أو الرقم + زر "افتح لينك التحويل"، وبعد التحويل بيبعت صورة التحويل في محادثة الواتساب.
- **إرسال الطلب:** عند الضغط على "إرسال على واتساب":
  1. يُرسل الطلب فورياً عبر `POST /api/orders` إلى السيرفر.
  2. يقوم السيرفر بإعادة حساب وتدقيق جميع الأسعار بالكامل ومطابقتها مع المنيو (حماية من أي تلاعب في أسعار المتصفح).
  3. يتم توليد رقم طلب تسلسلي رسمي يبدأ من `#1001` وتخزين الطلب بحالة "جديد" (`new`) في `data/orders.json`.
  4. يُفتح واتساب برسالة عربية رسمية منسقة (RTL نظيفة تماماً بدون إيموجي لتجنب التشوه  ومضبوطة باتجاه الكتابة)، تتضمن رقم الطلب والفرع والمنطقة والعميل والأصناف والإجمالي وطريقة الدفع.
  5. في حالة انقطاع الاتصال بالسيرفر، يتم إنشاء رقم محلي احتياطي (مثل `L-XXXX`) فوراً دون تعطيل إرسال الطلب عبر واتساب.

## نظام إدارة الطلبات (لوحة التحكم)
قسم **الطلبات** في لوحة التحكم يتيح إدارة ومتابعة الطلبات لحظة بلحظة:
- **تحديث حي (Live Polling):** فحص تلقائي للطلبات الجديدة كل 15 ثانية دون الحاجة لتحديث الصفحة، مع شارة حمراء توضح عدد الطلبات الجديدة في التبويب.
- **تنبيه صوتي (WebAudio Beep):** صوت تنبيه لطيف عند وصول أي طلب جديد، مع إمكانية تفعيله أو كتمه بزر سريع يُحفظ في المتصفح.
- **فلترة وتصفية مرنة:** عرض الطلبات (النشطة / جديد / قيد التجهيز / خرج للتوصيل / تم التسليم / ملغي / الكل) وفلترة بالتواريخ (اليوم / آخر 7 أيام / كل الفترات) وبحث فوري بالاسم أو الهاتف أو رقم الطلب.
- **دورة حياة الطلب وسير العمل:**
  - `جديد` ← زر "بدء التجهيز 👨‍🍳"
  - `قيد التجهيز` ← زر "خرج للتوصيل 🛵" (للدليفري) أو "تم التسليم ✓" (للتيك أواي)
  - `خرج للتوصيل` ← زر "تم التسليم ✓"
  - إمكانية الإلغاء مع تسجيل سبب الإلغاء في أي وقت.
- **أبلغ العميل بنقرة واحدة (WhatsApp Notify):** زر "💬 أبلغ العميل" يُنشئ رابط واتساب مباشر لرقم هاتف العميل برسالة مخصصة جاهزة بحسب حالة طلبه (تأكيد الاستلام / قيد التجهيز / خرج للتوصيل مع المندوب / تم التسليم / الاعتذار مع سبب الإلغاء).
- **طباعة فاتورة استلام حرارية (Thermal Receipt Ticket):** زر "🖨️ طباعة" يقوم بتنسيق فاتورة استلام أنيقة متوافقة مع طابعات الفواتير الحرارية مقاس 80mm تشمل اسم المطعم ورقم الطلب وبيانات العميل والأصناف والإجمالي وتفاصيل الدفع.
- **تنبيه تعديل الأسعار:** في حال حدوث أي اختلاف بين أسعار سلة العميل والأسعار المعتمدة على السيرفر، يظهر تنبيه تحذيري واضح على كارت الطلب.

## الهيكل
- `server.js`  السيرفر + API + رفع الصور (sharp) + إدارة الطلبات والتحقق من الأسعار + الجلسة
- `data/menu.json`  بيانات المنيو وإعدادات الفروع ومناطق التوصيل (تتعدل من اللوحة). `npm run seed -- --force` يرجّعها للأصل
- `data/orders.json`  قاعدة بيانات الطلبات المتسلسلة وسجل الحالات
- `public/`  المنيو (`index.html`, `js/app.js`, `js/cart.js`, `js/checkout.js`, `css/`) واللوحة (`admin/`)
- `public/uploads/`  الصور المرفوعة

## النشر والتخزين الدائم (مهم جداً)
اللوحة تحتاج **سيرفر Node** (ليست صفحة ثابتة). ينفع أي استضافة Node (VPS، Render، Railway، Fly.io…) بشرطين أساسيين:
1. **تخزين دائم (Persistent Volume / Storage):**
   - يلزم ربط مجلد `data/` كوحدة تخزين دائمة، لأنه يحتوي على:
     - `data/menu.json`: المنيو والفروع ومناطق التوصيل وطرق الدفع.
     - `data/orders.json`: جميع طلبات العملاء وسجل الحالات.
   - يلزم ربط مجلد `public/uploads/` لتخزين صور الأصناف وشعار المطعم.
   - بدون التخزين الدائم ستُفقد الطلبات وتعديلات المنيو عند إعادة تشغيل الحاوية أو السيرفر.
2. **HTTPS** + `NODE_ENV=production` + `ADMIN_PASSWORD` قوية.
